# 🚦 Traffic Congestion Prediction & Early Warning System

> Bachelor Thesis | TU Dortmund | 2025
> Machine Learning-based short-term traffic 
> congestion prediction for Smart City applications

## Overview
This project develops and compares three ML models 
(Random Forest, LSTM, XGBoost) for predicting traffic 
congestion 20 minutes in advance, combined with a 
prototype early warning system.
